Entity-Relationship (ER) Model

The database schema is fully normalized up to 3NF / BCNF. Below is the live rendered Crow's Foot ER Diagram:

erDiagram CATEGORIES ||--o{ BOOKS : "classifies (1:N)" AUTHORS ||--o{ BOOK_AUTHORS : "writes (1:N)" BOOKS ||--o{ BOOK_AUTHORS : "written_by (1:N)" BOOKS ||--o{ LOANS : "borrowed_in (1:N)" MEMBERS ||--o{ LOANS : "initiates (1:N)" STAFF_USERS ||--o{ LOANS : "issues (1:N)" LOANS ||--o| FINES : "incurs (1:1)" CATEGORIES { int category_id PK varchar name UK text description } AUTHORS { int author_id PK varchar name varchar country } BOOKS { int book_id PK varchar isbn UK varchar title int category_id FK int total_copies int available_copies } BOOK_AUTHORS { int book_id PK_FK int author_id PK_FK boolean is_primary_author } MEMBERS { int member_id PK varchar first_name varchar last_name varchar email UK varchar phone enum status } LOANS { int loan_id PK int book_id FK int member_id FK date issue_date date due_date date return_date enum status } FINES { int fine_id PK int loan_id FK_UK decimal amount enum payment_status }
